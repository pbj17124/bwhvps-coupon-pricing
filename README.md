## 优惠码怎么用才不亏：循环折扣是关键

搬瓦工优惠码和多数商家不同的地方在于折扣是**循环的**：下单时用了码，之后每次续费都自动按折后价执行，不会因为码后来过期就恢复原价。相当于在购买那一刻锁定了长期折扣。

算一笔账就能看出值不值得折腾：6.77% 放在年付 $169.99 的 CN2 GIA-E 上，一年省约 $11.5；如果这个折扣跟着你续费三五年，累计就是几十美元。反过来说，如果你下单时没填码，之后就算优惠码满天飞，也和你这台机器无关——折扣跟着订单走，不跟人走。

所以正确的顺序是：先确认优惠码有效，再下单。填码这一步放在选好套餐之后、付款之前，别跳过。
